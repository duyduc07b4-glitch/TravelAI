Hướng dẫn cài đặt nội bộ

AI Travel Companion

Trợ lý lập kế hoạch du lịch chạy AI hoàn toàn trên máy của bạn — không cloud, không tài khoản, không thể phát sinh chi phí. Làm theo các bước dưới đây, mất khoảng 10 phút.

Cần gì trước khi bắt đầu

  • Trình duyệt Chrome hoặc Edge bản gần đây (Firefox/Safari chưa hỗ trợ tốt các API cần dùng)
  • Khoảng 2 GB dung lượng trống ổ đĩa cho model AI
  • Mạng internet chỉ để tải lần đầu — sau đó AI chạy hoàn toàn offline
  • Python đã cài (chỉ để mở giao diện qua server local — xem bước 3)

Bước 1 — Nhận bộ file dự án

1

Xin 1 thư mục gồm 3 file sau từ người gửi cho bạn (Slack, Drive, USB đều được), lưu chung 1 chỗ trên máy — ví dụ ra Desktop:

app.htmlgiao diện chính
start-mac.commandkhởi chạy nhanh — macOS
start-windows.batkhởi chạy nhanh — Windows

Bước 2 — Cài AI chạy local (Ollama)

2

Cài Ollama

Vào ollama.com/download, tải bản macOS, mở file .dmg và kéo vào Applications. Mở app Ollama một lần — icon sẽ nằm ở thanh menu trên cùng, chạy nền tự động từ đó.

Sau đó mở Terminal và tải model AI:

Terminalollama pull llama3.2
Tải khoảng 2GB, mất vài phút tùy mạng. Chỉ cần làm một lần.
2

Cài Ollama

Vào ollama.com/download, tải bản Windows, chạy file .exe và làm theo trình cài đặt. Ollama sẽ tự chạy nền và nằm ở khay hệ thống (system tray) từ đó về sau.

Sau đó mở PowerShell hoặc Command Prompt và tải model AI:

PowerShellollama pull llama3.2
Tải khoảng 2GB, mất vài phút tùy mạng. Chỉ cần làm một lần.

Bước 3 — Khởi động & dùng thử

3

Mở app

Double-click start-mac.command. Lần đầu macOS có thể chặn vì file chưa rõ nguồn gốc — chuột phải vào file → Open → xác nhận Open lần nữa.

Terminal sẽ mở và trình duyệt tự bật trang app.

3

Mở app

Double-click start-windows.bat. Nếu Windows hiện cảnh báo "Windows protected your PC" (do file tải từ mạng), bấm More info → Run anyway.

Cửa sổ dòng lệnh sẽ mở và trình duyệt tự bật trang app.

4

Kết nối AI

Trong app, ở góc trên: ô Server để nguyên http://localhost:11434, ô model để llama3.2, bấm "Kiểm tra kết nối". Chấm tròn chuyển xanh là xong — thử ngay tab "Lịch trình".

Dùng được từ điện thoại trong cùng Wi-Fi Tuỳ chọn

AI chạy trên máy tính, điện thoại chỉ mở trang web và gọi sang qua mạng nội bộ — không cần tải gì trên điện thoại.

Trên máy chạy Ollama, cần bật cho phép truy cập mạng + CORS:

Terminal — trước khi mở Ollamalaunchctl setenv OLLAMA_HOST "0.0.0.0"
launchctl setenv OLLAMA_ORIGINS "*"
PowerShell — rồi khởi động lại Ollamasetx OLLAMA_HOST "0.0.0.0"
setx OLLAMA_ORIGINS "*"

Khởi động lại Ollama, rồi tìm địa chỉ IP mạng LAN của máy đó (macOS: System Settings → Wi-Fi → Details; Windows: ipconfig trong cmd, xem dòng IPv4).

Trên điện thoại (cùng Wi-Fi), mở http://[IP-máy]:8765/app.html, rồi trong app đổi Server thành http://[IP-máy]:11434.

Xử lý sự cố thường gặp

"Không kết nối được tới Ollama" Cả hai hệ điều hành
Kiểm tra Ollama có đang chạy không — macOS: icon trên thanh menu; Windows: icon ở khay hệ thống. Nếu không thấy, mở lại app Ollama rồi bấm "Kiểm tra kết nối" trong trang web lần nữa.
App báo "không thấy model llama3.2"
Model chưa tải xong hoặc gõ sai tên. Chạy lại ollama pull llama3.2 và đợi đến khi thấy chữ "success".
Trả lời rất chậm hoặc máy nóng/giật
Máy cấu hình thấp sẽ chạy chậm hơn — đây là bình thường với AI chạy local. Có thể thử model nhẹ hơn: ollama pull llama3.2:1b, rồi đổi ô model trong app thành llama3.2:1b.
Giọng đọc trong tab "Trợ lý giọng nói" nghe robot
Đây là giọng đọc mặc định của hệ điều hành, app không kiểm soát được chất lượng. Trong app, thử đổi sang giọng khác ở ô "Giọng đọc" nếu có nhiều lựa chọn. Trên macOS có thể cài thêm giọng "Enhanced/Premium" tại System Settings → Accessibility → Spoken Content.
Địa chỉ, giờ mở cửa, số điện thoại AI gợi ý có đáng tin không?
Không nên tin tuyệt đối. AI chạy local không có dữ liệu thời gian thực, nên tên quán có thể đúng nhưng giờ mở cửa hay số điện thoại có thể sai. App luôn có nút "Xem bản đồ" cạnh mỗi địa điểm — bấm vào để xem thông tin thật trên Google Maps trước khi đi.
